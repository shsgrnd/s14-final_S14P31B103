# DB 덤프 안내

## 1. 개요

GitCat은 서버형 DB가 아니라 로컬 SQLite DB를 사용한다. 본 폴더는 제출용 DB 산출물을 보관하는 위치이다.

## 2. 현재 포함 파일

| 파일명 | 설명 |
| --- | --- |
| `gitcat.db` | 로컬 GitCat SQLite DB 복사본 |

## 3. 원본 경로

현재 복사 기준 원본 경로는 아래와 같다.

```text
.vscode/gitcat/gitcat.db
```

## 4. 복사 정보

| 항목 | 값 |
| --- | --- |
| 복사 일시 | `2026-05-19 13:12:16 KST` |
| 원본 파일 형식 | SQLite DB |
| 원본 파일 크기 | `229376 bytes` |

## 5. 포함 데이터 설명

본 DB는 GitCat 로컬 메타데이터 저장소이며, 다음 범주의 데이터가 포함될 수 있다.

- 세션 정보
- 스냅샷 메타데이터
- 변경 기록
- 원복 이력
- 병합 분석 결과 메타데이터
- AI 추천 이력

참고:
- 실제 스냅샷 원본 파일 본문은 파일 시스템 경로에 저장될 수 있다.
- 민감정보는 원칙상 `SecretStorage`에 저장되므로 DB에 직접 저장하지 않는 구조를 사용한다.

## 6. 민감정보 확인

| 항목 | 상태 |
| --- | --- |
| 개인정보 포함 여부 | `최종 제출 전 확인 필요` |
| 테스트 데이터 정리 여부 | `최종 제출 전 확인 필요` |
| 외부 배포 가능 여부 | `최종 제출 전 확인 필요` |

## 7. 제출 시 권장 사항

1. 최종 시연 직전 최신 데이터로 DB를 다시 복사한다.
2. 불필요한 테스트 데이터가 있는지 확인한다.
3. 민감정보 또는 발표와 무관한 데이터가 없는지 검토한다.
4. 필요 시 `gitcat_latest.dump` 같은 추가 export 파일을 함께 제공한다.
