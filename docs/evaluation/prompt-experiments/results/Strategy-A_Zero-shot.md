## TEST-01: 변수명 선언 키워드 중복 수정

### 📥 Input
```text
Ours: const a = 1; 
Theirs: let a = 1; 
Base: var a = 1;
```

### 🤖 AI Answer
주어진 충돌 상황을 분석해보겠습니다.

---

### 상황 정리

- **Base (공통 조상)**:  
  ```js
  var a = 1;
  ```

- **Ours (내 변경사항)**:  
  ```js
  const a = 1;
  ```

- **Theirs (상대 변경사항)**:  
  ```js
  let a = 1;
  ```

---

### 충돌 원인 분석

- Base에서는 변수 `a`를 `var`로 선언했습니다.
- Ours는 `a`를 `const`로 변경했습니다.
- Theirs는 `a`를 `let`으로 변경했습니다.

즉, 두 브랜치 모두 변수 선언 방식을 변경했는데, 서로 다른 키워드(`const` vs `let`)를 사용했습니다. 이 때문에 Git이 자동 병합하지 못하고 충돌이 발생한 것입니다.

---

### 차이점 및 의미

- `var`: 함수 스코프, 재선언 및 재할당 가능
- `let`: 블록 스코프, 재선언 불가, 재할당 가능
- `const`: 블록 스코프, 재선언 및 재할당 불가

`const`는 상수 선언, `let`은 재할당 가능한 변수 선언입니다.

---

### 해결책 제안

1. **변수의 용도 파악**  
   - `a`가 변경되지 않는 값이라면 `const`가 적합합니다.
   - `a`가 이후에 재할당될 가능성이 있다면 `let`을 사용해야 합니다.

2. **팀 내 합의**  
   - 변수 선언 방식을 통일하는 것이 좋습니다.
   - 가능하면 `const`를 기본으로 하고, 재할당이 필요한 경우에만 `let` 사용 권장.

3. **코드 수정 예시**

   - 만약 `a`가 상수라면:
     ```js
     const a = 1;
     ```
   - 만약 `a`가 재할당될 수 있다면:
     ```js
     let a = 1;
     ```

---

### 결론

- 충돌 원인은 두 브랜치가 변수 선언 키워드를 다르게 변경했기 때문입니다.
- 해결하려면 변수의 사용 목적에 따라 `const` 또는 `let` 중 하나를 선택하고, 해당 선언으로 통일하면 됩니다.

---

필요하면 더 구체적인 코드 컨텍스트를 알려주시면, 더 적합한 해결책을 제시해드릴 수 있습니다!

## TEST-02: 동일 함수 내 로직 충돌

### 📥 Input
```text
Ours: function add(a, b) { return a + b + 1; } 
Theirs: function add(a, b) { return a + b + 2; } 
Base: function add(a, b) { return a + b; }
```

### 🤖 AI Answer
### 충돌 상황 분석

- **Base**: 원래 함수는 `add(a, b) { return a + b; }`로 단순히 두 수를 더하는 기능입니다.
- **Ours**: `return a + b + 1;`로 변경되어, 두 수의 합에 1을 더하는 로직으로 수정되었습니다.
- **Theirs**: `return a + b + 2;`로 변경되어, 두 수의 합에 2를 더하는 로직으로 수정되었습니다.

### 충돌 원인

- **기능 변경 충돌**: Base에서 단순 덧셈이었는데, Ours와 Theirs 모두 결과값에 상수를 더하는 변경을 했습니다.
- Ours는 +1, Theirs는 +2로 서로 다른 상수를 더하도록 변경되어, 자동 병합이 불가능한 상태입니다.

### 해결책 제시

1. **의도 파악**: 왜 각각 +1, +2를 더했는지 확인해야 합니다.
   - 만약 두 변경 모두 의미가 있다면, 합산하거나 다른 로직으로 조정할 수 있습니다.
   - 아니면 하나를 선택하거나, 새로운 로직으로 대체해야 합니다.

2. **예시 해결안**:
   - 단순히 더한 값을 반환하려면, 둘 중 하나를 선택:
     ```js
     function add(a, b) { return a + b + 1; } // Ours 선택
     ```
   - 혹은 두 변경을 합산:
     ```js
     function add(a, b) { return a + b + 3; } // 1 + 2 합산
     ```
   - 또는 의미에 맞게 새로운 로직 작성:
     ```js
     function add(a, b, increment = 1) { return a + b + increment; }
     ```

3. **커뮤니케이션 권장**: 변경한 개발자들과 상의하여 어떤 값이 맞는지, 혹은 새로운 요구사항이 있는지 확인하는 것이 가장 좋습니다.
