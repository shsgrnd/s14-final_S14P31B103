## TEST-01: 변수명 선언 키워드 중복 수정

### 📥 Input
```text
Ours: const a = 1; 
Theirs: let a = 1; 
Base: var a = 1;
```

### 🤖 AI Answer
안녕하세요! 주신 충돌 상황을 분석해보면, 세 가지 버전에서 변수 선언 방식이 다르게 변경된 것을 알 수 있습니다.

- **Base (기준 버전)**: `var a = 1;`  
- **Ours (내 쪽 변경)**: `const a = 1;`  
- **Theirs (상대방 변경)**: `let a = 1;`

### 충돌 원인 분석

Git 충돌은 같은 코드 영역에서 서로 다른 변경이 이루어졌을 때 발생합니다. 여기서는 변수 선언 키워드가 각각 `var`에서 `const`와 `let`으로 변경되었기 때문에 충돌이 발생했습니다.

- `var`는 함수 스코프(function-scoped)를 가지며, 재선언과 재할당이 모두 가능합니다.
- `let`은 블록 스코프(block-scoped)를 가지며, 재할당은 가능하지만 재선언은 불가능합니다.
- `const`는 블록 스코프이며, 재선언과 재할당 모두 불가능합니다.

즉, 서로 다른 변수 선언 방식이 적용되면서 코드의 동작 방식과 의도가 달라질 수 있기 때문에 Git은 자동 병합을 하지 않고 충돌로 처리한 것입니다.

### 해결 방법 제안

1. **코드 의도 파악**  
   - 해당 변수 `a`가 이후에 재할당되는지 확인하세요.
   - 재할당이 없다면 `const`가 적합합니다.
   - 재할당이 필요하다면 `let`을 사용해야 합니다.
   - `var`는 ES6 이후 권장되지 않으므로 가능하면 `let`이나 `const`를 사용하는 것이 좋습니다.

2. **팀 내 합의**  
   - 변수 선언 방식을 팀 내 코딩 컨벤션에 맞게 결정하세요.
   - 보통은 `const`를 기본으로 하고, 재할당이 필요한 경우에만 `let`을 사용합니다.

3. **충돌 해결**  
   - 위 내용을 바탕으로 한 쪽 코드를 선택하거나, 필요에 따라 코드를 수정하여 충돌을 해결하세요.

---

필요하다면 충돌 해결을 위한 구체적인 Git 명령어나 절차도 안내해 드릴 수 있으니 편하게 말씀해 주세요!

## TEST-02: 동일 함수 내 로직 충돌

### 📥 Input
```text
Ours: function add(a, b) { return a + b + 1; } 
Theirs: function add(a, b) { return a + b + 2; } 
Base: function add(a, b) { return a + b; }
```

### 🤖 AI Answer
안녕하세요! 주신 세 가지 버전의 코드를 보니 Git에서 발생하는 충돌 상황을 이해하는 데 도움이 될 것 같아요.

- **Base**: `function add(a, b) { return a + b; }`  
  원래의 기준 코드입니다. 두 수를 더하는 단순한 함수죠.

- **Ours**: `function add(a, b) { return a + b + 1; }`  
  사용자가 작업한 변경사항으로, 기존 함수에 `+1`을 더하는 로직이 추가되었습니다.

- **Theirs**: `function add(a, b) { return a + b + 2; }`  
  다른 사람이 작업한 변경사항으로, 기존 함수에 `+2`를 더하는 로직이 추가되었습니다.

---

### 충돌의 기술적 원인

Git 충돌은 같은 파일의 같은 부분을 서로 다르게 수정했을 때 발생합니다. 여기서는 `add` 함수의 반환값을 계산하는 부분이 세 버전에서 모두 다르게 변경되었기 때문에 충돌이 발생한 것입니다.

- Base에서는 `a + b`였는데,
- Ours는 `a + b + 1`,
- Theirs는 `a + b + 2`로 변경되어 서로 다른 결과를 내도록 수정되었죠.

Git은 자동으로 어느 쪽을 선택해야 할지 판단할 수 없기 때문에 충돌로 표시하고, 개발자가 직접 어떤 코드를 최종적으로 사용할지 결정하도록 합니다.

---

### 해결 방법 제안

1. **기능적 의도 파악**  
   왜 각각 `+1`과 `+2`를 더했는지 목적을 명확히 해야 합니다. 두 변경사항이 모두 필요한지, 아니면 한 쪽만 반영해야 하는지 판단하세요.

2. **코드 병합**  
   예를 들어 두 변경사항을 모두 반영하려면 아래처럼 수정할 수 있습니다.  
   ```javascript
   function add(a, b) {
       return a + b + 3; // 1 + 2를 합산
   }
   ```
   또는 두 변경사항이 독립적이라면 별도의 함수로 분리할 수도 있습니다.

3. **테스트**  
   병합 후에는 반드시 기능 테스트를 수행해 의도한 대로 동작하는지 확인하세요.
